# Rabbit Tracks — Design Notes

## Design Direction

I want Rabbit Tracks to be easy to understand and comfortable to use. The interface should help users focus on their research instead of making them figure out how the application works.

I'm starting with simple wireframes so I can work through the layout and user experience before spending time on colors, typography, and visual details.

## Navigation

I'm using a left-hand sidebar as the main navigation.

The sidebar will contain:

- Dashboard
- Research Library
- Questions
- Discoveries
- Sources
- Settings

I chose this layout because I want the main sections to remain easy to access as users move through the application.

## Dashboard

The dashboard will act as a starting point rather than a statistics page.

I don't want to fill it with numbers or analytics that don't help someone continue their research. Instead, I'll use the space to highlight recently updated entries and make it easy to start something new.

## Creating Research Entries

Creating an entry will take users to its own page instead of opening a pop-up or placing an editor directly inside the dashboard.

Questions and discoveries will share one editor. The selected entry type will determine where the saved entry appears in the application.

## Research Library

The research library will provide a central place to browse saved entries.

Each entry should show enough information to help users recognize it without having to open every item individually.

## Wireframes

I'm creating the initial wireframes in Excalidraw. I'll use them to work through the layout, navigation, and user flow before implementing the screens.

I'll update this document as the design becomes more defined.
